# Contributing

Thank you for helping make this project better for beginners and small shop owners.

## How to contribute

1. **Check the idea first.** Open an issue and describe what you want to add or fix, in one or two sentences. A maintainer will say yes or suggest a change before you write code.
2. **One step, one change.** One pull request per fix or per tutorial improvement. Do not mix several changes into one pull request.
3. **Keep it beginner-friendly.** Plain HTML, CSS, and JavaScript only. No build step, no framework, no external library, no API key. If a beginner cannot open the file and see it work, it does not belong here.
4. **Test before you send.** Open every HTML file you changed in a browser. Click every button. Check the browser console for errors. If you changed a step, run through its README instructions yourself.

## What we accept

- Bug fixes (a button that does not work, a total that adds up wrong).
- Clearer explanations in a step's README.
- A new step, if it teaches one new concept and follows the same format (one concept, full working code, run instructions, one challenge).
- Translations of a step's README into Urdu or another language.

## What we do not accept

- Frameworks, build tools, or paid services.
- Real phone numbers, real shop prices presented as real, or copied code from other projects.
- Gambling, betting, pirated software, or paid-placement requests.

## Style

- Simple English words. Short sentences.
- Every price in the code is a demo price in PKR and must be labelled as a demo price.
- No phone numbers anywhere in the code or docs.

Suggestions in Roman Urdu or English are both welcome.
