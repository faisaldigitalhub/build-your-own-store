# Build Your Own Store 🛍️

> Learn how an online store works by building one yourself — step by step, with plain HTML, CSS, and JavaScript. No build step. No API keys. No backend. Everything runs in your browser, fully offline.

Inspired by the idea behind [build-your-own-x](https://github.com/codecrafters-io/build-your-own-x) — the most-starred repository on GitHub — but for online stores: the thing a small shop actually needs.

## Who is this for?

- A small shop owner (bakery, boutique, beauty salon, electronics shop, or home-based seller) who wants to understand how a store works before paying for one.
- A beginner learning to code who wants a real project, not another "Hello World".
- A student who wants to build a store for a family shop or a class project.

You do not need to know how to code. Each step explains one idea in simple words, then shows the full working code.

## The roadmap

| Step | What you build | What you learn |
| --- | --- | --- |
| [01 — Product Catalog](01-product-catalog/) | A page that shows products from a data file, with a category filter | Data vs. design: the page is a template, the products are data |
| [02 — Shopping Cart](02-shopping-cart/) | Add to cart, change quantities, see the total | State: keeping track of what the customer chose |
| [03 — Checkout via WhatsApp Order](03-checkout-whatsapp-order/) | A checkout form that builds a WhatsApp order message | No backend needed: the order travels as a message |
| [04 — Search and Sort](04-search-and-sort/) | Live search, sort by price and name | Filtering and sorting a list in plain JavaScript |
| [05 — Admin: Add a Product](05-admin-add-product/) | A small admin page to add a product | Saving data in the browser with localStorage |

Do the steps in order. Each one uses what the previous step taught.

## How to run it

1. Download or clone this repository.
2. Open `index.html` in your browser (double-click it). That page links to all five steps.
3. Or open any step's `index.html` directly — every step runs on its own.

No install. No server. No account. If your browser can open a file, you can run this store.

> **Demo prices:** every price in this project is a **demo price in PKR**, made up for learning. They are not real shop prices. Change them to your own prices before using any of this for a real shop.

## What you need

- A web browser (Chrome, Firefox, Edge, Safari — any modern one).
- A text editor to change the code (VS Code is free, or even Notepad).
- Optional: Python 3, if you want to serve the files over local HTTP (`python3 -m http.server`).

## How each step is written

Every step folder has:

- `index.html` — the full working code for that step (open it and it works).
- `README.md` — what the step teaches, how to run it, and one small challenge to try yourself.

One concept per step. One runnable example. One challenge. That is the whole method.

## What this is NOT

- Not a ready-made shop for real customers. Real shops also need real payment, delivery, and order management.
- Not a copy of anyone else's store code. Every line here was written for this project.
- Not financial or business advice. Prices, fees, and delivery rules change — check them yourself.
